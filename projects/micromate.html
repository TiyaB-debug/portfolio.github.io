MicroMate

A prototype for tracking macronutrients and managing recipes, with a React interface and nutrition data from the USDA

My role
Frontend development, data integration, and interface design
Tools
React, JavaScript, Python, Figma, HTML, CSS
Timeline
July 2026 to present

What I built

My frontend work brought nutrition tracking and recipe management into a React prototype. Components and client-side state management support the interface in JavaScript.

Working with nutrition data

Custom Python scripts retrieve nutrition data from the USDA FoodData Central API and put it into a consistent format. My integration work included investigating and correcting data inconsistencies.

Design and iteration

Figma mockups provided the starting point for my HTML and CSS layouts. Feedback on the working prototype then informed changes to layout and usability.

Current stage

MicroMate is an ongoing proof of concept. The work so far covers the interface, client-side state, nutrition data integration, and prototype iteration.
