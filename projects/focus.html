The problem

A work session needs a clear beginning and room for breaks. This project brings a timer and supporting productivity tools into one interface.

My contribution

I built a React-based timer experience with customizable settings and supporting task-management features.

The approach

The interface brings focus sessions, breaks, aesthetic backgrounds, and Spotify integration together. Customization lets users adjust the environment around the way they prefer to work.

Where it stands

The application is available to explore through the live site. The interface combines timing and task management in a single web experience.

What I’m thinking about

A productivity interface needs a clear hierarchy so the controls support the work instead of competing for attention.
